# Contributing
faircenter is a proof of concept and is not open for outside contributions for now. The code is published so it can be seen and demonstrated, under a restrictive licence that allows no use, copying or distribution without written permission (see [LICENSE](LICENSE)). Pull requests and forks are not being accepted at this stage.

Ideas, corrections and questions are welcome. Raise one by email to stephen.whitmarsh@proton.me, or through the repository if you have access. If the licensing opens up later, this file will say so and set out how to contribute.
