# Contributing
faircenter is a proof of concept, and for now it is not open for outside contributions. The code is published so it can be seen and demonstrated, under a restrictive licence that allows no use, copying or distribution without written permission (see [LICENSE](LICENSE)). Pull requests and forks are not being accepted at this stage.

Ideas, corrections and questions are very welcome all the same. The best way to raise one is by email to Stephen Whitmarsh at stephen.whitmarsh@proton.me, or through the repository if you have access to it. If the licensing opens up later, this file will say so and set out how to contribute in practice.
